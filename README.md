# Sol Art

My art portfolio website, hosted on GitHub Pages.

**View it live: <https://anukzc.github.io/sol_art.github.io/>**

Follow along on Instagram: [@sol.__.art](https://www.instagram.com/sol.__.art/).

## Project structure

```
index.html        The whole site: gallery grid and footer
images/
  fulls/          Full-size artwork shown in the popup viewer
  thumbs/         Thumbnails shown in the gallery grid
  background.PNG  Site background
assets/
  css/            Compiled styles (main.css is the one in use)
  sass/           Source styles, only needed if you rebuild the CSS
  js/             jQuery, the Poptrox lightbox, and the template's scripts
  webfonts/       Font Awesome icons
```
